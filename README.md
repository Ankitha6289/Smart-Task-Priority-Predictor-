# Smart Task Priority Predictor

A Python Flask web application that predicts task priority using a Decision Tree Classifier and a rule-based scoring engine.

## Quick Start

```bash
# 1. Create and activate virtual environment (optional but recommended)
python -m venv venv
venv\Scripts\activate

# 2. Install dependencies
pip install -r requirements.txt

# 3. Train the model (also generates data/tasks.csv)
python train_model.py

# 4. Start the app
python app.py
```

Open **http://127.0.0.1:5000** in your browser.

## Priority Scoring Formula

```
score = (business_impact × 4) + (urgency × 3) + (dependency_count × 2) + deadline_points
```

**Deadline points:** Overdue=20, ≤2 days=15, ≤7 days=10, ≤14 days=7, >14 days=3  
**Effort adjustment:** <3h → +5 pts (quick win) | >20h → −5 pts  
**Labels:** 80–100 = Critical · 60–79 = High · 40–59 = Medium · 0–39 = Low
